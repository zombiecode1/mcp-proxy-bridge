কী প্রমাণিত হল:

  • SHA-256 hash → deterministic: same data always produces same hash
  • Write → Store hash → Read back → Compare → Auto-mark verified
  • Data tampered হলে hash mismatch হবে → verified: 0
  • Fake hash (wrong data) → matches: false — সঠিকভাবে ডিটেক্ট করে

প্রাসঙ্গিক Trust Checker Experiment শিক্ষা:

⚠️ SHA-256 = ইন্টিগ্রিটি প্রুফ, সত্যতা প্রুফ নয়।
SHA-256 প্রমাণ করে তথ্য পরিবর্তন হয়নি, কিন্তু তথ্য সঠিক ছিল — সেটা নয়।
Write verification + cross-source verification একসাথে ব্যবহার করলেই পুরো ছবি পাওয়া যায়।
