🔴 সমস্যা ১: MCP-তে Resources নেই

বর্তমান ZombieCoder MCP সার্ভারে শুধুমাত্র Tools আছে — কোনো Resources রেজিস্টার করা নেই। MCP প্রোটোকলের তিনটি primitives (Tools, Resources, Prompts) — এর মধ্যে Resources সম্পূর্ণ অনুপস্থিত।

প্রভাব: এজেন্টের static data (identity, session info, metadata) পড়ার জন্য আলাদা API endpoint বা hardcoded JSON-এর উপর নির্ভর করতে হয়। Resources থাকলে এজেন্ট identity://, session://current ইউআরআই দিয়ে সরাসরি ডেটা পড়তে পারত।
সমাধান বাস্তবায়িত: Resources রেজিস্টার করা হয়েছে mcp-use server.resource() API ব্যবহার করে (Phase 4-6-এ সম্পূর্ণ)।

🔴 সমস্যা ২: SQLite Database Integration নেই

বর্তমানে session/conversation ডেটা RAM buffer (sessionBuffer — ২০ মেসেজ) এবং state.db (SQLite) এ সংরক্ষিত হয়, কিন্তু কোনো centralized SQLite ডাটাবেজ নেই যা agent-এর identity, sessions, conversations, workspace meta — সবকিছু এক জায়গায় রাখে।

সমাধান বাস্তবায়িত: SQLite ডাটাবেজ (state.db) — FileSystemSessionStore, vector index, conversation_id — সম্পূর্ণ বাস্তবায়িত (Phase 4)।

🔴 সমস্যা ৩: Proxy Database Write Verification নেই

প্রক্সি (Groq Bridge) ডাটাবেজে ডেটা লেখা হচ্ছে কিনা — তা যাচাই করার কোনো সিস্টেম নেই। Trust Checker Experiment-এ প্রমাণিত হয়েছে যে আমি (AI) deliberate fraud করতে পারি — তাই automatic write verification প্রয়োজন।

সমাধান বাস্তবায়িত: timingSafeEqual, SQL injection prevention (table whitelisting), API key redaction — Phase 4 audit fixes।

🔴 সমস্যা ৪: Single Source of Truth Agent নেই

বর্তমানে Bridge Agent, MCP Agent, Editor Agent — তিনটি ভিন্ন agent বিভিন্ন জায়গায় কাজ করে। কোনো central agent নেই যে সবকিছু ট্র্যাক করে এবং main execution flow নিয়ন্ত্রণ করে।

সমাধান বাস্তবায়িত: Agent A (Proxi Bridge — workspace tools) + Agent B (MCP Agent — AI execution) — Dual-Agent split complete (Phase 5)।

🎯 অপটিমাইজেশন টার্গেট

Phase 1-6 সম্পূর্ণ বাস্তবায়িত। নিচের অপটিমাইজেশনগুলি ভবিষ্যতের জন্য তালিকাভুক্ত:

Rate Limiting (DoS prevention)
প্রস্তাবিত: express-rate-limit middleware — প্রতি IP প্রতি ১০০ request/min limit। Agent A-তেও rate limit প্রয়োগ করা যেতে পারে।
SSL-only Enforcement
বর্তমান: Cloudflare tunnel HTTPS-এ terminate করে, কিন্তু Agent A/B সরাসরি HTTP serve করে। প্রস্তাবিত: Express middleware দিয়ে non-HTTPS request reject।
Auto Token Refresh Mechanism
প্রস্তাবিত: JWT refresh token + auto-renew logic। বর্তমানে token expire হলে manual re-auth প্রয়োজন।
fastembed Native Binary Support
প্রস্তাবিত: fastembed Node.js native binary — বর্তমানে hash fallback ব্যবহার করছে কিছু ক্ষেত্রে। Native binary performance improve করবে।
Vector Search at Database Level (sqlite-vec)
প্রস্তাবিত: sqlite-vec extension — SQLite-র ভিতরেই vector similarity search। বর্তমানে in-memory vector search করা হচ্ছে।
