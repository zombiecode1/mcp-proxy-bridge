🎯 MCP = OpenAI-Compatible Consumer

MCP (Model Context Protocol) কোনো নির্দিষ্ট ব্রিজ বা প্রক্সির সাথে বাঁধা নয়। MCP শুধু OpenAI-compatible JSON-RPC রেসপন্স চায় — সেটা Groq থেকে আসুক, Ollama থেকে আসুক, বা অন্য কোনো OpenAI-compatible endpoint থেকে।

সিদ্ধান্ত: MCP কখনো বন্ধ হবে না যতক্ষণ পর্যন্ত যেকোনো একটি OpenAI-compatible endpoint থেকে রেসপন্স পাওয়া যায়। ব্রিজ ডাউন থাকলেও ব্যাকআপ endpoint থেকে কাজ চালিয়ে যাবে।

৩. Environment Variable Fallback Logic DESIGN

📋 প্রস্তাবিত Environment Variables

# Primary LLM source (REQUIRED — MCP এটা দিয়ে boot হবে)
LLM_BASE_URL=http://localhost:5001/v1
LLM_API_KEY=your-key-here
LLM_MODEL=auto

# Fallback LLM source (OPTIONAL — primary fail হলে ব্যবহার করবে)
LLM_FALLBACK_BASE_URL=https://api.zombiecoder.my.id/v1
LLM_FALLBACK_API_KEY=
LLM_FALLBACK_MODEL=qwen3-coder-next:cloud

# Local fallback (OPTIONAL — সব fail হলে শেষ চেষ্টা)
LLM_LOCAL_BASE_URL=http://127.0.0.1:5010/v1
LLM_LOCAL_MODEL=llama3.2:1b

⚙️ Fallback Logic (Pseudo-code)

FUNCTION getActiveLLM():
    sources = [
        { url: LLM_BASE_URL,       key: LLM_API_KEY,       model: LLM_MODEL },
        { url: LLM_FALLBACK_BASE_URL, key: LLM_FALLBACK_API_KEY, model: LLM_FALLBACK_MODEL },
        { url: LLM_LOCAL_BASE_URL, key: '',                 model: LLM_LOCAL_MODEL },
    ]

    FOR source IN sources:
        IF source.url == '' OR source.url == undefined:
            CONTINUE

        TRY:
            response = POST source.url + '/chat/completions'
                WITH {
                    model: source.model,
                    messages: [{role:'user', content:'ping'}],
                    max_tokens: 1
                }
                HEADERS { Authorization: 'Bearer ' + source.key }

            IF response.status == 200:
                LOG 'Active LLM: ' + source.url + ' | model: ' + source.model
                RETURN source  // ← MCP stays UP with this source

        CATCH error:
            LOG 'Source failed: ' + source.url + ' — ' + error.message
            CONTINUE  // ← try next source

    // All sources failed
    LOG 'CRITICAL: No LLM source available'
    THROW 'No responsive OpenAI-compatible endpoint found'
মূলনীতি: MCP কোনো নির্দিষ্ট ব্রিজের উপর নির্ভরশীল নয়। এটি যে কোনো OpenAI-compatible endpoint থেকে কাজ করবে। ব্রিজ পরিবর্তন হলে MCP পুনরায় সেট করতে হবে না — শুধু env var পরিবর্তন।
৪. Database Schema — Multi-Source Aware SQLite

🗄️ টেবিল: sessions — মাল্টি-সোর্স ট্র্যাকিং

প্রতিটি সেশন কোন LLM source ব্যবহার করছে এবং সেটার স্বাস্থ্য কী — তা ট্র্যাক করে।

কলামটাইপবর্ণনা
id INTEGER PK Auto-increment primary key
session_id TEXT UNIQUE UUID v4 — MCP session identifier
workspace_id TEXT Workspace identifier (nullable)
primary_base_url TEXT Primary LLM endpoint (from LLM_BASE_URL)
primary_model TEXT Primary model name
fallback_base_url TEXT Fallback LLM endpoint (from LLM_FALLBACK_BASE_URL)
fallback_model TEXT Fallback model name
active_base_url TEXT Currently active endpoint (primary or fallback)
active_model TEXT Currently active model
source_priority INTEGER 1=primary, 2=fallback, 3=local — কোন source active
status TEXT active / degraded / offline
health_status TEXT ok / degraded / failed — শেষ health check-এর ফল
last_health_check TEXT ISO timestamp — কখন শেষ health check করা হয়েছে
created_at TEXT ISO timestamp — session creation
last_active TEXT ISO timestamp — শেষ activity
metadata_json TEXT JSON blob — extra metadata (rate limits, errors, etc.)

🗄️ টেবিল: llm_sources — উৎস রেজিস্ট্রি

সব উপলব্ধ LLM source-এর রেজিস্ট্রি। প্রতিটি source-এর হেলথ ও মডেল লিস্ট ট্র্যাক করা হয়।

কলামটাইপবর্ণনা
id INTEGER PK Auto-increment
name TEXT Friendly name: groq-bridge, ollama-cloud, ollama-local
base_url TEXT Endpoint URL
api_key_env TEXT Env var name for API key (e.g., LLM_API_KEY) — value never stored
priority INTEGER Order of precedence: 1=highest, 2, 3
health_status TEXT ok / degraded / failed
last_verified TEXT ISO timestamp — last successful health check
models_json TEXT JSON array — available models from /v1/models
is_active INTEGER 0=disabled, 1=active
error_count INTEGER Consecutive failure count (auto-disable after N)
created_at TEXT ISO timestamp
API Key Policy: API keys কখনো ডাটাবেজে সংরক্ষণ করা হবে না। শুধু env var নাম সংরক্ষণ করা হবে। রানটাইমে process.env[api_key_env] থেকে পড়া হবে।

৫. কেন এই ডিজাইন গুরুত্বপূর্ণ RESILIENCE

🔐 ব্রিজ-অ্যাগনস্টিক আর্কিটেকচারের সুবিধা

  1. রেসিলিয়েন্স: Groq Bridge ডাউন থাকলেও Ollama থেকে কাজ চলে — MCP কখনো অফলাইন হয় না
  2. পোর্টেবিলিটি: যেকোনো OpenAI-compatible endpoint ব্যবহার করা যায় — শুধু env var পরিবর্তন
  3. টেস্টেবিলিটি: লোকাল Ollama দিয়ে টেস্ট, প্রোডাকশনে Groq — একই কোড, আলাদা env
  4. কস্ট অপ্টিমাইজেশন: প্রাথমিক source fail হলে সস্তা fallback-এ স্যুইচ (degraded mode)
  5. ভেন্ডর লক-ইন নেই: Groq → Ollama → Local — যেকোনো কম্বিনেশন
  6. ট্রান্সপারেন্সি: কোন source কোন response দিয়েছে — DB-তে লগ করা থাকে

⚠️ Trust Checker Experiment থেকে শিক্ষা

পূর্ববর্তী Trust Checker Experiment-এ প্রমাণিত হয়েছে যে ক্লাউড মডেল deliberate fraud করতে পারে। মাল্টি-সোর্স আর্কিটেকচার এই ঝুঁকি কমায়:

  • এক source-এর response অন্য source দিয়ে cross-verify করা যায়
  • write_log টেবিলে hash + read-back verification — কোন source কী লিখেছে তা ট্র্যাকযোগ্য
  • source_used কলাম → কোন AI model/endpoint response দিয়েছে তা জানা যায়
